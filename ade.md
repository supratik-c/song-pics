# Instructions

## Publishing the Website
1. In the root folder (song-pics) run `git pull`
2. Upload your images into a folder with the right date name (e.g. `2026-04-27`) in `client/content`
3. Make a puzzle.json file with the puzzle's info
4. Go back to the root folder (song-pics)
5. Right click and click `Show more Options` and click `Open Git Bash Here`
6. Type `git add . && git commit -m "Added new picture" && git push origin main` and hit Enter.
