# Instructions

## Publishing the Website
1. In the root folder (song-pics), open Git Bash (you may need to right click in the folder, and click `Show More Options`) and run `git pull`
2. Upload your images into a folder with the right date name (e.g. `2026-04-27`) in `client/content/puzzles/`
3. Make a puzzle.json file with the puzzle's info
4. In Git Bash, copy and paste the following command and hit Enter: `git add . && git commit -m "Added new picture" && git push origin main`.
