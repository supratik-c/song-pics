# Branding assets

Third-party brand marks used to link out to an external service. Unlike the
game's own art, these are not ours to redraw or recolor — see the full
asset-register entry in [docs/commercial.md](../../../../../docs/commercial.md).

## kofi-logo.webp

- **Source:** Ko-fi's public brand-assets page,
  https://more.ko-fi.com/brand-assets (wordmark preview image, served from
  `cdn.prod.website-files.com`).
- **Acquired:** 2026-08-05.
- **Modifications:** format conversion only (AVIF -> lossless WebP) and a
  downscale from 1475x402 to 600x164 for a sane file size at the display size
  this button uses. No recoloring, cropping, or redrawing.
- **Licence basis:** Ko-fi's brand guidelines permit creators to use the
  unmodified logo to link to their own Ko-fi page; the mark must not be
  stretched, distorted, or otherwise significantly altered.
- **Used by:** `client/src/views/supportView.ts`.
